# Quote of the Day

A lightweight, browser-based quote generator that displays a random quote and author in a centered card. Quotes are loaded from the [DummyJSON quotes API](https://dummyjson.com/quotes/random), and the current quote can be shared on X.

## Features

- Load a random quote on page load or with **New Quote**
- Share the displayed quote using an X post
- Responsive viewport setup for browser use
- Styled with custom CSS, Google Fonts, and Font Awesome icons

## Project structure

```text
index.html   Page structure
style.css    Layout and visual styles
script.js    Quote loading and X sharing behavior
```
